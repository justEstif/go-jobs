# Plan: Custom DaisyUI Theme for go-jobs

## Design Context

**Product**: Self-hosted job aggregator targeting startup job seekers.  
**Users**: Active job hunters who want signal over volume — technical, self-sufficient, value efficiency.  
**Personality**: Minimal & quiet. The chrome disappears; the content is the interface.  
**Color direction**: Near-monochrome — slate grays with a single precise accent. No hue drama.  
**Mode**: Light only.  
**Border radius**: Slightly rounded (professional, not boxy, not bubbly).

---

## What We're Building

A custom DaisyUI 5 theme named `"go-jobs"` defined via `@plugin "daisyui/theme"` in `styles/input.css`. The theme replaces the current generic `light` theme referenced via `data-theme="light"` in `layout.templ`.

### Aesthetic Direction: *Quiet Precision*

Near-monochrome with cool-tinted slate grays. A single restrained accent — a precise slate-blue — used only at the 10% rule: CTAs, focus rings, active states, links. Everything else recedes. The job listings become the visual focus.

- **No gradient text, no glassmorphism, no purple-blue gradients** (AI slop avoidance)
- **No pure black or pure white** — all surfaces and text use OKLCH with subtle chroma tint
- **Tinted neutrals** — all grays carry `0.01–0.02` chroma at hue `240` (cool slate blue tint)
- **Depth** enabled (`--depth: 1`) for subtle component elevation
- **Noise** disabled (`--noise: 0`) — clean, not grainy

---

## Color Palette (OKLCH)

All colors use OKLCH for perceptual uniformity.

### Base surfaces (cool-tinted, never pure white/gray)
| Token | Value | Role |
|---|---|---|
| `base-100` | `oklch(98% 0.005 240)` | Page background — near-white with cool tint |
| `base-200` | `oklch(95% 0.008 240)` | Elevated surfaces, sidebar, navbar |
| `base-300` | `oklch(91% 0.010 240)` | Input backgrounds, dividers, borders |
| `base-content` | `oklch(18% 0.015 240)` | Primary text — near-black, cool-tinted |

## Shape & Size Tokens

```css
--radius-selector: 0.5rem;   /* checkboxes, toggles, badges — softer */
--radius-field:    0.25rem;  /* inputs, buttons, tabs — subtle */
--radius-box:      0.375rem; /* cards, alerts, modals — refined */
--size-selector:   0.25rem;
--size-field:      0.25rem;
--border:          1px;
--depth:           1;        /* subtle 3D elevation on components */
--noise:           0;        /* no grain */
```

## Files to Modify

### 1. `styles/input.css`
- Replace current `@plugin "../daisyui.mjs";` (no config) with a configured plugin block:
  - Set theme `"go-jobs"` as `--default`
  - Add `@plugin "../daisyui.mjs/theme"` block (or `daisyui/theme` syntax depending on local plugin path) with all color and shape tokens

**Important**: The local DaisyUI is loaded as `../daisyui.mjs`. The theme plugin path syntax for local files needs to be `../daisyui.mjs/theme` — verify this matches DaisyUI 5's standalone distribution structure. If that path doesn't resolve, define colors via `@theme` CSS variables as a fallback.

### 2. `components/layout.templ`
- Change `data-theme="light"` → `data-theme="go-jobs"` on the `<html>` element

## Full CSS to Write

```css
@import "tailwindcss";

@source not "../tailwindcss";
@source not "../daisyui{,*}.mjs";

@plugin "../daisyui.mjs" {
  themes: go-jobs --default;
}

@plugin "../daisyui.mjs/theme" {
  name: "go-jobs";
  default: true;
  prefersdark: false;
  color-scheme: light;

  --color-base-100: oklch(98% 0.005 240);
  --color-base-200: oklch(95% 0.008 240);
  --color-base-300: oklch(91% 0.010 240);
  --color-base-content: oklch(18% 0.015 240);

  --color-primary: oklch(42% 0.10 255);
  --color-primary-content: oklch(97% 0.005 240);

  --color-secondary: oklch(65% 0.04 240);
  --color-secondary-content: oklch(97% 0.005 240);

  --color-accent: oklch(55% 0.08 220);
  --color-accent-content: oklch(97% 0.005 240);

  --color-neutral: oklch(22% 0.015 240);
  --color-neutral-content: oklch(94% 0.005 240);

  --color-info: oklch(58% 0.12 230);
  --color-info-content: oklch(97% 0.005 230);

  --color-success: oklch(55% 0.14 155);
  --color-success-content: oklch(97% 0.005 155);

  --color-warning: oklch(70% 0.15 75);
  --color-warning-content: oklch(20% 0.05 75);

  --color-error: oklch(55% 0.18 25);
  --color-error-content: oklch(97% 0.005 25);

  --radius-selector: 0.5rem;
  --radius-field: 0.25rem;
  --radius-box: 0.375rem;

  --size-selector: 0.25rem;
  --size-field: 0.25rem;

  --border: 1px;
  --depth: 1;
  --noise: 0;
}
```

> **Note on plugin path**: The `../daisyui.mjs/theme` path assumes the standalone `.mjs` distribution ships a `/theme` sub-export. If the build fails with a resolution error, the fallback is to define the custom theme using `@theme` CSS variables directly in `input.css` (overriding DaisyUI's CSS custom properties under the `[data-theme="go-jobs"]` selector).

## Verification

After implementing:

```bash
# Build CSS (requires ./tailwindcss binary and daisyui.mjs to be present)
./tailwindcss -i styles/input.css -o static/css/tailwind.css --minify

# Compile check
go build ./...

# Run dev server
mise run dev
```

Then open the browser and verify:
- `<html data-theme="go-jobs">` is set
- Navbar background is cool near-white (`base-200`), not harsh white
- Primary buttons (`btn-primary`) are dark slate-blue, not the DaisyUI default blue
- Inputs have subtle rounding and cool-tinted background
- No visual regression on auth forms, about page, contact form
- All text passes WCAG AA contrast (base-content on base-100 should be ~10:1)
