go-jobs

self-hosted startup job search

Find better jobs. Keep full control of your data.

go-jobs is a self-hosted job aggregator that pulls from Greenhouse, Lever, and Ashby, enriches postings with structured metadata, and gives you both a fast web UI and a CLI to search, filter, and track your pipeline.

CLI

Install the CLI from npm and use it against the live app or your own instance:

npm install -g @justestif/go-jobs
jobs search --query "backend go"
jobs login
jobs pipeline

To target the hosted app: jobs --base-url https://jobs.estifanos.cc <command>

Self-hosting

docker pull ghcr.io/justestif/go-jobs:latest

Then run with Docker Compose or plain Docker. See the self-hosting guide for env vars and full setup.
