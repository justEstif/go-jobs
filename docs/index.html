self-hosted startup job search

Find better jobs. Keep full control of your data.

go-jobs is a self-hosted job aggregator that pulls from Greenhouse, Lever, and Ashby, enriches postings with structured metadata, and gives you both a fast web UI and a CLI to search, filter, and track your pipeline.

What it does

Aggregate from startup ATS sources

Scrapes jobs from Greenhouse, Lever, and Ashby, stores everything in your own PostgreSQL database, and keeps postings fresh via scheduled runs.

Enrich jobs for real filtering

Classifies role type, seniority, remote policy, location, and tech stack, so filtering is meaningful instead of keyword guessing.

Track applications in one place

Move jobs through interested, applied, interviewing, offer, rejected, and withdrawn states from either the UI or terminal.

Own your stack and uptime

You host it. You run the schedule. You keep your data and workflow without depending on a third-party board.

Architecture at a glance

  • Core-first hexagonal structure: ports and services in internal/core
  • Driven adapters for Postgres, ATS scrapers, enrichment, and scheduler
  • Driving adapters for HTTP handlers, middleware, CLI commands, and jobs loop
  • Single composition root in cmd/jobs/main.go

Read the full technical docs in ARCHITECTURE.md and interfaces.md.

Quick start

mise install
docker-compose up -d
mise run setup
mise run dev

Then open http://localhost:3000.

For production-friendly local deployment steps, see Self-hosting.
